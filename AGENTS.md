# AGENTS.md

## Project scope

This repository contains a website project. Keep changes focused on the user's request and preserve unrelated work.

## Working guidelines

- Inspect the existing structure and conventions before editing.
- Prefer small, targeted changes over broad rewrites.
- Do not overwrite or delete user-created assets unless explicitly requested.
- Reuse existing components, styles, and utilities when available.
- Keep desktop and mobile behavior in mind for interface changes.
- Do not add dependencies unless they are necessary for the requested work.

## Verification

- Run the most relevant available checks after making changes.
- For visual changes, verify the affected pages at desktop and mobile sizes when practical.
- Report any checks that could not be run and any assumptions made.

## Git hygiene

- Do not discard unrelated working-tree changes.
- Do not commit, push, or create branches unless the user asks.
