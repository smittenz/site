- Do not add dependencies unless they are necessary for the requested work.

## Verification

- Run the most relevant available checks after making changes.
- For visual changes, verify the affected pages at desktop and mobile sizes when practical.
- Report any checks that could not be run and any assumptions made.

## Git hygiene

- Do not discard unrelated working-tree changes.
- Do not commit, push, or create branches unless the user asks.
